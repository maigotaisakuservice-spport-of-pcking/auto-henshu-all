# AI Video Production Pipeline "The Studio" - 完全マスター仕様書

## 1. プロジェクト概要
本プロジェクトは、GitHub Actions上でAIを用いて動画の自動編集、検閲、BGM生成、およびYouTubeへのアップロードを行う「完全自律型スタジオ」である。

## 2. 推定処理時間（ダウンロード〜投稿完了まで）
30分以上の動画は「長編モード」が自動発動し、最適化されます。

| 元動画の長さ | 合計時間目安 | 判定 |
| :--- | :--- | :--- |
| 5分 | 約60分 | ✅ 安全 |
| 30分 | 約180分 | ✅ 安全 |
| 180分 (3h) | 約355分 | 🔴 限界 |

## 3. セットアップガイド (推奨：サービスアカウント方式)
リフレッシュトークン不要で、3時間の動画でも安定して投稿できる **「サービスアカウント」** 方式を推奨します。

### ステップ1：サービスアカウントJSONの取得
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成。
2. **API有効化**: 「ライブラリ」から **YouTube Data API v3** を有効化。
3. **作成**: 「認証情報」>「認証情報を作成」> **「サービス アカウント」** を選択。
4. **鍵の取得**: 作成されたメールアドレスをクリック > 「キー」タブ > 「鍵を追加」> 「新しい鍵を作成」 > **JSON** を選択してダウンロード。
5. **Secrets登録**: JSONの中身を全て GitHub Secrets `YOUTUBE_SERVICE_ACCOUNT_JSON` に貼り付け。

### ステップ2：YouTube チャンネルへの招待
1. [YouTube Studio](https://studio.youtube.com/) > 「設定」 > **「権限」** をクリック。
2. **「招待」** をクリックし、ステップ1で作成した **サービスアカウントのメールアドレス** を入力。
3. アクセス権を **「編集者」** に設定して保存。
4. **【重要】** 招待後、そのアカウントの管理画面（サブ垢等）で招待を承認してください。

## 4. 必須設定：GitHub Secrets 一覧
| シークレット名 | 推奨度 | 役割 |
| :--- | :--- | :--- |
| `YOUTUBE_SERVICE_ACCOUNT_JSON` | **推奨** | サービスアカウントのJSON (手順3) |
| `REAL_NAME` | **必須** | 検閲対象の本名（カンマ区切り） |
| `YOUTUBE_CLIENT_ID` | 予備 | OAuth ID |
| `YOUTUBE_CLIENT_SECRET` | 予備 | OAuth Secret |
| `YOUTUBE_REFRESH_TOKEN` | 予備 | OAuth Refresh Token |

## 5. Q&A
**Q: 実行ログに本名が出ませんか？**
A: はい。「ログ・ステルス」機能により、全ての出力から本名をリアルタイムで消去します。

**Q: なぜダウンロードでエラーが出るのですか？**
A: Google Drive のリンクが「直リンク」になっていない可能性があります。`&export=download` が付いた共有リンクを使用してください。
